## So lädst Du es hoch

1. Repo `apertushealth/dpc-social-assets` im Browser öffnen.
2. **Add file → Upload files**.
3. Den entpackten Ordner `w4` als Ganzes in das Fenster ziehen. GitHub legt die Ordnerstruktur automatisch an.
4. Commit-Nachricht z. B. `W4 Assets` → **Commit changes**.

Danach hier kurz Bescheid geben — dann prüfe ich die URLs und lege die Buffer-Posts an. **Terminieren heißt veröffentlichen**, das passiert erst nach Deiner ausdrücklichen Freigabe.
